# Meithera — demonstration MVP

Proposed Irish fractional property investment platform (Stake Ireland). **Demonstration only — no real investments, payments or tokens. Not authorised or regulated by the Central Bank of Ireland.**

Work in progress — see `CLAUDE.md` for status and the remaining build plan, and `docs/briefs/` for the full specification.

```bash
pnpm install
pnpm dev   # http://localhost:3000
```
